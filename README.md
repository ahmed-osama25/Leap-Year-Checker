# 📅 Leap Year Checker

A simple **C++ OOP project** that checks whether a year is a leap year or not.

The project also allows the user to check multiple years and find all leap years within a specific range.

## 🚀 Features

* Check if a specific year is a leap year.
* Check multiple years at once.
* Display all leap years within a given range.
* Simple interactive menu.
* Uses Object-Oriented Programming (OOP).

## 🧠 Leap Year Rules

A year is a leap year if:

* It is divisible by **400**.
* OR it is divisible by **4** but **not divisible by 100**.

Examples:

* `2000` → Leap Year ✅
* `2024` → Leap Year ✅
* `1900` → Not a Leap Year ❌
* `2023` → Not a Leap Year ❌
